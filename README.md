# Four Leaves website redesign

An unsolicited, speculative redesign of the Four Leaves bakery website (fourleaves.com.sg),
built as a portfolio piece by Loo Say Hien. Not affiliated with, endorsed by, or connected to
Four Leaves Pte Ltd.

Everything runs as one self contained page with hash routing, so it can be hosted as static
files with no build step:

- `index.html` — the whole site: home, cakes, cake pages, bread and buns, our story, outlets,
  careers, promotions, membership, the ordering flow, and the support pages.
- `views/` — cake photography, one set per size, plus the short films and slices.
- `origin/` — the ingredient origin photography and clips.
- `img/` — website imagery, buns, logos and posters.
- `hero.mp4`, `hero-poster.jpg`, `hero-still.jpg` — the film on the home page.

Product photography is from fourleaves.com.sg. Grower and origin imagery, the films, and the
grower stories are AI generated concept content made for this redesign, and are labelled as
such on the site.
